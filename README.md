# RANK-OF-A-MATRIX
## Aim:
To write a python program to find the rank of a matrix
## Equipment’s required:
1. 	Hardware – PCs
2. 	Anaconda – Python 3.7 Installation / Moodle-Code Runner
## Algorithm:
Step 1: Start the program and import the NumPy module.

Step 2: Define the matrix using `np.array()` and store it in a variable named `matrix`.

Step 3: Use `np.linalg.matrix_rank(matrix)` to calculate the rank and store it in `rank`.

Step 4: Print the value of `rank` and end the program.

## Program:
```
#Program to find the rank of a matrix.
#RegisterNumber: DHARUN M 25018453
#RegisterNumber: 212225230057
import numpy as np
matrix = np.array([[1,2,3],[3,6,9]])
rank = np.linalg.matrix_rank(matrix)
print(rank)
```
